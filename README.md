# Bespokit Core Workbench

A modular MFT-style workbench designed by Bespokit.

The Core Workbench is designed as the foundation of a modular workshop system, allowing individual units to be combined and adapted to suit different workshop layouts and requirements.

## Specifications

| Specification      | Dimension / Detail |
| ------------------ | ------------------ |
| Width              | 1152 mm            |
| Depth              | 768 mm             |
| Height             | 977 mm             |
| Main body material | 18 mm MR MDF       |
| Drawer material    | 15 mm MR MDF       |
| MFT hole diameter  | 20 mm              |
| MFT hole spacing   | 96 mm              |

The design also incorporates side-mounted holes for the **Benchdog Tools Quad Hinge** system.

## Construction

The Core Workbench is designed to be assembled using:

* 8 mm Lamello Cabineo connectors
* Threaded inserts
* Suitable castors

The modular units are designed around a specific castor arrangement. Check the drawings and model carefully before purchasing hardware, as hardware dimensions and specifications may change.

## Assembly

No assembly animation is currently provided.

The Fusion model, STEP assembly and accompanying drawings are provided to allow the workbench to be understood and assembled.

## Materials

The design was developed around 18 mm moisture-resistant (MR) MDF for the main structure and 15 mm MR MDF for the drawers.

Different sheet materials may be used, but changing material thickness or properties may affect dimensions, clearances and structural performance.
